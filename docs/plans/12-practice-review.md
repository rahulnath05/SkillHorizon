# 12 Practice review

Parent: [Master plan](README.md)

Status: `not-started`

Depends on [11 Catalogue](11-catalogue.md) being `done`.

## Outcome

The competency-lead workspace opens Briefing, profile requests for the practice, the review room, and Sign-off. Aligned pack rows can be batch-marked. An exception cannot. Seal stays the command already built, and it is refused while an exception has no recorded decision. Accepting a profile request does not publish a benchmark.

## Out of scope

The baseline heatmap, market demand, Mira’s colleague desk, and a global cohort.
