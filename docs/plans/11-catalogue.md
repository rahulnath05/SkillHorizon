# 11 Catalogue

Parent: [Master plan](README.md)

Status: `not-started`

Depends on [10 Manager workspace](10-manager-workspace.md) being `done`.

## Outcome

The L&D workspace opens Overview, the skill taxonomy, the benchmark workspace, profile requests, and the approval queue. Draft edits stay in the authoring zone. Publish stays the command already built. A profile request can become a draft profile and does not publish itself. The approval queue shows drafts that L&D has sent. An unsent draft is not waiting on the competency lead.

## Out of scope

Activation launch, the assessment studio, the seal screen, and Mira.
