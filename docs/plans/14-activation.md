# 14 Activation

Parent: [Master plan](README.md)

Status: `not-started`

## Outcome

The L&D workspace opens the activation centre. Launch uses the wave admission already built. A population over the zone budget is still refused. Rolling intake admits one mapped person into an open wave without resetting that wave. An unmapped person is refused and is not written into the zone. The studio page that shows rolling intake is slice 16. This slice stores the admission that page will read.

## Out of scope

Adaptive item selection, the item bank, and Mira.
