# 08 Employee home

Parent: [Master plan](README.md)

Status: `done`

Depends on [06 Territories](06-territories.md) being `done`.

## Outcome

The employee workspace opens Dashboard, My skills, and My documents, beside the assessment and path already built. Dashboard, skills, and documents read stored rows for the signed-in person. Skills come from the sealed result and the benchmark in force. Documents list evidence metadata already stored for that person. File bytes stay in object storage.

## Out of scope

Mira, My tasks, manager pages, the item bank, and another person’s records.
