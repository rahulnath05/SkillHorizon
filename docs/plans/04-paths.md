# 04 Paths

Parent: [Master plan](README.md)

Status: `done`

Depends on [03 Learning](03-learning.md) being `done`.

## Outcome

A development path is built in the learning service from a sealed result and the benchmark version in force. Evidence metadata is stored apart from the file bytes. A manager validation records the relationship that was in force. A completion reported for an external provider updates the same step record.

## Out of scope

Practice packs, seals, cohort operations, and Mira. The external completion can be supplied by a test adapter. A live learning-platform connector is not required to finish this slice.
