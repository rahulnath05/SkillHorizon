# 09 Employee tasks

Parent: [Master plan](README.md)

Status: `not-started`

Depends on [08 Employee home](08-employee-home.md) being `done`.

## Outcome

My tasks lists what the signed-in person owes. Opening a task shows the close flow. Closing a task uses the evidence command already on the path. Closing a task does not change a sealed proficiency. The list is work owed, not a course catalogue.

## Out of scope

The manager review queue, Mira, and a second proficiency scale.
