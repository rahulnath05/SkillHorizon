# 16 Assessment operations

Parent: [Master plan](README.md)

Status: `not-started`

Depends on [15 Assessment bank](15-assessment-bank.md) being `done`.

## Outcome

The assessment studio opens Overview, the programme scorecard, assessment operations, declared versus assessed, the pilot report, and rolling intake. Declared level is a separate row from the sealed proficiency. Writing a declaration does not change the sealed result. Scorecard, operations, and the pilot report are snapshots of counts and durations. Rolling intake reads the admissions stored in slice 14. An employee grant cannot open the studio.

## Out of scope

Browsing response text, warehouse export, and Mira.
