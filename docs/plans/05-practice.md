# 05 Practice

Parent: [Master plan](README.md)

Status: `done`

Depends on [04 Paths](04-paths.md) being `done`.

## Outcome

L&D submits a pack. A competency lead seals it, including aligned profiles and exceptions. Cohorts are bounded operating groups. Practice readiness is a snapshot with an as-of time, read by the page rather than computed from live skill rows.

## Out of scope

A second residency zone, warehouse export, and Mira. A global cohort of everyone on a job profile is not created.

## Micro-steps

| Step | Work | Status |
|------|------|--------|
| 05.1 | Pack of proposed profile rows, with aligned, tightening, and new-bar classifications | done |
| 05.2 | Seal command for a competency lead inside the practice scope, committed with the published versions it seals | done |
| 05.3 | An unsealed pack does not change the published baseline | done |
| 05.4 | Cohort create inside a practice and a country or org unit, rejected when membership would pass the operating maximum | done |
| 05.5 | Worker writes a practice readiness snapshot from sealed results, the benchmark in force, and membership | done |
| 05.6 | Practice page reads that snapshot and shows the as-of time | done |
| 05.7 | A command that changes a score or a benchmark marks the snapshot dirty and does not recompute the practice in the request | done |
